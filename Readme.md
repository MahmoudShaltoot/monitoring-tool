# monitoring-tool-app
Monitoring service for APIs which periodically checks service status and immediately sends push notifications to subscribed devices when downtime is detected

# Running Server locally
## Prerequisites

First, ensure you have the following installed:

1. Node - Download and Install latest version of Node: [NodeJS](https://nodejs.org/en)
2. RabbitMQ - Download and Install [RabbitMQ](https://www.rabbitmq.com/tutorials/tutorial-one-javascript.html)
